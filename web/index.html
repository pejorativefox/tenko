Tenko Linux 6

Packages for the Tenko 6 (Workstation) base system, built with the self-hosted Tenko container toolchain. Package versions roll independently of the distro release.

01Quick start

Add the repository definition and install the base meta-package:

# add the repo
sudo curl -o /etc/yum.repos.d/tenko-6.repo \
  https://tenko.pjfox.xyz/packages/6/tenko-6.repo

# install the base system
sudo dnf install tenko-base

The Tenko 6 repository lives at https://tenko.pjfox.xyz/packages/6/. The previous https://repo.pjfox.xyz/packages/13.1/ path remains valid as a compatibility alias.

Or use it directly, without installing a repo file:

sudo dnf --repofrompath=tenko-6,https://tenko.pjfox.xyz/packages/6/ \
  --disablerepo='*' install tenko-base

The XFCE 4.20 desktop (X11 only, no Wayland) is in the same repository:

sudo dnf install xfce-desktop

The repository is unsigned (gpgcheck=0).

02Install media

A small UEFI-only installer ISO. Installation downloads the packages from this repository, so the machine needs network access while installing (the ISO itself carries no RPMs):

# download and verify
curl -LO https://tenko.pjfox.xyz/iso/tenko-installer.iso
curl -LO https://tenko.pjfox.xyz/iso/tenko-installer.iso.sha256
sha256sum -c tenko-installer.iso.sha256

# write it to a USB stick
sudo dd if=tenko-installer.iso of=/dev/sdX bs=4M status=progress oflag=sync

496 MiB · kernel 7.3.1 · installs the runtime base and the XFCE desktop from this repository; install the build toolchain afterwards with dnf install tenko-base.

The current images predate the rename and the Tenko 6 release; they are republished under these Tenko names at the next image rebuild. A future rebuild may also publish tenko-installer-6.iso and tenko-rootfs-6.tar.gz, with the unversioned names kept as aliases.

A container rootfs built from this repository is published too. It is the build image (gcc, make, Python 3.15, Perl, CMake/meson, rpm/dnf, createrepo_c) and can be imported directly:

curl -LO https://tenko.pjfox.xyz/rootfs/tenko-rootfs.tar.gz
curl -LO https://tenko.pjfox.xyz/rootfs/tenko-rootfs.tar.gz.sha256
sha256sum -c tenko-rootfs.tar.gz.sha256
podman import tenko-rootfs.tar.gz localhost/tenko/rootfs:6

312 MiB gzip · 130 packages · regenerated from the repository with scripts/make_base_image.sh.

03What’s inside

Base system

94 packages — the base package set plus tenko-basefs, sysconfig, release, and the RPM toolchain.

Toolchain

gcc 16.2.0, binutils 2.47, make 4.4.1, rpm 4.18.1, meson 1.12.1.

Runtime

glibc 2.44 + glibc-locales (886 locales), systemd 262.1, python 3.15.2, openssl 4.1.0.

Kernel

linux-kernel 7.3.1 and linux-modules with virtio-blk/pci, serial, and ext4 built in for QEMU testing.

05Notes

The repository is unsigned and lives on a single origin. The build is self-hosted: all 93 specs rebuild offline inside localhost/tenko/base:r13.1, and build/rootfs-selfhost is installed from these RPMs. The pre-rename image tag remains valid until the image rebuild.
