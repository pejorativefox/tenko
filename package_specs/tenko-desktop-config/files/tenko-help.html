Tenko 6 help

This is the fallback help page for Tenko 6 (Workstation). It is opened for help: URIs when an application or the desktop requests documentation that is not installed under a more specific help id.

Installed documentation

  • Manual pages: man <command>.
  • Installed help collections live under /usr/share/help/<id>/index.html.
  • Desktop applications open their own help through xdg-open help:<id>.

Common tasks

  • Package management: dnf install, dnf upgrade, dnf search.
  • Repository definition: /etc/yum.repos.d/tenko-6.repo.
  • Session logs: journalctl --user and journalctl -b.
